# Phase 1 Objective

This project is a small C++ systems lab focused on clean model structure, register-style access, descriptor queues, completion tracking, and profiling.

## Month 1 focus

- Week 1: project setup, register-style interface, first benchmark
- Week 2: ownership, move-only resource wrappers, configuration-style metadata
- Week 3: data layout, descriptor structures, command notification
- Week 4: data movement simulation, benchmark discipline, profiling notes

## Success criteria

By the end of Month 1, the project should have:

- A clean CMake build
- A simple register map
- A synthetic device model
- A descriptor structure
- A basic queue path
- A smoke test
- A benchmark
- Weekly notes
- A small interview question bank
