# Platform I/O Concepts

Use this file to collect short explanations in your own words.

## Register-style interface

A register-style interface exposes named or offset-based locations that software can read or write.

## Mapped region

A mapped region is a software-visible window used to access a component's control interface.

## Descriptor

A descriptor is a compact record that describes work to be performed.

## Notification

A notification is a small control action that tells the model new work is available.

## Completion

A completion is a record produced after work is processed.

## Data movement simulation

Data movement simulation estimates the cost or accounting of moving bytes without implementing a full real-world transport.
